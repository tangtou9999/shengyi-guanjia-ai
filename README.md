# 生意管家 AI

面向小微服务商家的移动端优先经营管理工具。

## 当前版本

- **V0.6.0**：已完成预约可直接登记订单，自动带入客户和服务价格；订单与预约建立关联，同一预约禁止重复生成订单，完成预约到收入记录的业务闭环。
- 数据保存在当前浏览器 LocalStorage；尚未接入真实 AI 模型、云数据库、账号系统、跨设备同步或线上支付。自动化浏览器测试覆盖桌面端与移动端的员工管理、预约冲突和预约转订单流程。
- 当前仍是本地演示版，不适合保存真实客户隐私或作为正式财务账簿。备份文件由用户自行保管；离线能力只缓存应用外壳，不代表云端同步。

## 在线预览（GitHub Pages）

GitHub Pages 已配置为 GitHub Actions 部署来源；由 GitHub 自动生成的 Pages 部署流程负责发布，项目另有独立的浏览器质量检查流程。

首次启用需要仓库管理员在 GitHub 打开：

**Settings → Pages → Build and deployment → Source → GitHub Actions**

保存后，后续推送到 `main` 会自动部署。网站地址通常为：

`https://tangtou9999.github.io/shengyi-guanjia-ai/`

部署状态可在仓库的 **Actions** 页面查看。不要额外添加第二套 Pages 部署工作流，以免与 GitHub 自动生成的部署流程争抢同一个 Pages artifact。

## 主要能力

- 经营总览、客户、预约、订单、支出、服务项目、员工与经营分析。
- 本地数据导出与经过结构校验的备份恢复。
- 恢复前自动下载当前数据副本。
- 支持浏览器缓存应用外壳，网络中断后可重新打开已缓存界面。
- Playwright 桌面端和移动端核心流程回归测试。

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 研发原则

数据准确优先于 AI 自动化；重要写操作必须经过确认；后端接入前必须实现身份认证、租户隔离、备份、权限控制和审计日志。
